# Bundled webfonts

Google Sans is the SIL Open Font License 1.1 variable font from
[google/fonts](https://github.com/google/fonts/tree/main/ofl/googlesans).
The file here is a subset covering the scripts the Mudal UI uses: Latin,
Cyrillic, Arabic, Devanagari, Sinhala and Thai. The licence is `OFL.txt`
beside this file. Fonts are served from this site rather than a font CDN,
so visiting the page sends nothing to a third party.
