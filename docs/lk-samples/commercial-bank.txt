# Source: owner-supplied, personal phone, masked (card reduced to last 4 digits
# "#4101", the 10-digit identifier in the "Credit for Rs." messages reduced to
# 8XXXXXXXX15).
# Format: one SMS per block, blocks separated by a blank line. Order is exactly
# as pasted by the owner (NOT chronological).
#
# Bank      : Commercial Bank of Ceylon (CBC / "combank")
# Sender ID : not supplied by the owner - CONFIRM (likely COMBANK / CBC / 8000x)
# Card      : debit card ending #4101
# Currency  : LKR (card SMS) and "Rs." (branch credit SMS)
# Dates     : dd/MM/yy hh:mm AM/PM on card SMS; time-only on branch credits
# Samples   : 18 SMS (15 purchases, 1 ATM withdrawal, 2 branch credits)
# Range     : 25/11/25 01:44 PM - 07/03/26 04:25 PM
# Note      : no parser exists for this bank yet - see docs/FORK_PLAN.md
#             (Phase 3, priority order: Commercial Bank first).
#
# Distinct message shapes (all must parse to a transaction):
#
#   1) Card purchase - "Dear Cardholder, Purchase at <merchant> for LKR <amt>
#      on <dd/MM/yy hh:mm AM/PM> has been authorised on your debit card ending
#      #4101."
#      -> EXPENSE, merchant = <merchant>, card = 4101
#      -> NOTE: the bank says "authorised", not "debited". Treat as a spend.
#
#   2) ATM withdrawal - "Withdrawal at <location> for LKR <amt> on <dd/MM/yy
#      hh:mm AM/PM> from card ending #4101."
#      -> EXPENSE (cash), no merchant name beyond the ATM location.
#
#   3) Branch credit - "Credit for Rs. <amt> to <10-digit id> at <hh:mm> at
#      DIGITAL BANKING DIVISION"
#      -> INCOME, no date in the body, amount prefix is "Rs." not "LKR".
#
# Edge cases to keep in mind when writing fixtures:
#   - Two different currency prefixes in one bank ("LKR" vs "Rs.").
#   - Merchant names contain "&", "_" (e.g. "Finagle Minimart _ NSBM"), double
#     spaces are absent but underscores are, and some names are truncated by the
#     bank ("Finagle Minimart _ NSBM CHomagama" - note the typo "CHomagama",
#     and "TERRA LOUNGE CAFE & RESKURUNEGALA KGLK").
#   - 12-hour clock with AM/PM, two-digit year (yy) - different from Sampath's
#     dd/MM/yyyy.
#   - No available balance / "Avl Bal" line in any of these messages.
#   - Several messages are near-duplicates of the same merchant (SERENTY INN
#     HOMAGAMA x7, H P H DULANJAYA x2, Finagle Minimart x2).
#   - The branch-credit messages have no date at all - the SMS timestamp is the
#     only date source.
